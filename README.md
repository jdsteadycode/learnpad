# 📝 Learnpad

is an approach to create a comfortable, usable writing space for my personal use.

**problem** I faced some problems in traditional notepad during my personal learning of `Namaste JavaScript, React` series - messy writing, no syntax highlighting for my code blocks in raw text, no proper formatting and sometimes md formatting shows conflicting stuff.

**solution** A minimal space to write raw natural notes while keeping things readable and with proper code-block highlighting for code blocks if written.

## ✨ Features

* Large and comfortable writing area for natural note-taking
* Designed with code-friendly learning notes in mind
* Clean, calm, and minimal writing-focused UI
* Responsive layout for small screens.


## 🚀 Version 

The current version **v1.0.3** focuses on establishing a stable and comfortable writing interface.

**UPDATE**:
* updated `html code` by adding note editor structure.
* updated `css code` by adding re-usable classes and some minimal styles for note editor output.
* added `js code` which currently allows writing raw text and viewing it right away containing `html, js, output` code block highlighting.
* stable and minimal yet, modern `html, js, output` code block(s) highlighting.
* minimal text wrapping for long notes.

## ⚠️ Notable Issues

The current version has following issues:

* Output/ View area size is a bit small and compact.
* No dedicated `syntax-highlighting` for each code block content.

## 🚧 In development
Currently not implemented:

* Code block highlighting for `input` code block (which can be bash / terminal / console instructions).
* Note saving or file handling.

These features may be explored and implemented gradually as the project evolves.
