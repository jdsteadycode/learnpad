# 📝 Learnpad

is an approach to create a comfortable, usable writing space for my personal use.

**problem** I faced some problems in traditional notepad during my personal learning of `Namaste JavaScript, React` series - messy writing, no syntax highlighting for my code blocks in raw text, no proper formatting and sometimes md formatting shows conflicting stuff.

**solution** A minimal space to write raw natural notes while keeping things readable and with proper syntax highlighting for code blocks if written.

## ✨ Features

* Large and comfortable writing area for natural note-taking
* Designed with code-friendly learning notes in mind
* Clean, calm, and minimal writing-focused UI
* Responsive layout for small screens.


## ⚠️ Notable Issues

The current version provides the initial UI foundation only. The actual editor behavior is still under development.

Currently not implemented:

* Syntax highlighting
* Automatic code detection
* Automatic code formatting
* Note saving or file handling


These features may be explored and implemented gradually as the project evolves.

## 🚀 Version 

The current version **v1.0** focuses on establishing a stable and comfortable writing interface.

Hence, currently only containing stable `HTML` and `CSS` structure exists and functionality is in development
